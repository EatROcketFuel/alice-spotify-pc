# Alice PC Controller (Lite): Яндекс Алиса → MQTT → Spotify на Windows 11

Фоновая программа для Windows 10/11, которая живёт в системном трее и выполняет голосовые
команды Алисы:

- «Алиса, включи Спотифай» / «выключи Спотифай» — запуск и закрытие Spotify Desktop;
- «следующий трек», «предыдущий трек», «пауза» — через глобальные медиаклавиши;
- «включи колонку» / «выключи колонку» — переключение звука **только Spotify** между колонкой
  и наушниками (системный звук и другие программы не трогаются).

Это **Lite-версия без поиска треков**: не нужны ключи Spotify, вход через браузер, Yandex Cloud
и Premium. Версия с поиском лежит в папке `full/` (в ZIP-архиве — `alice-spotify-pc-full`).

Цепочка работы:

```
Алиса → «Умный дом Яндекса» → навык-мост (WQTT и т. п.) → MQTT-брокер → эта программа на ПК
                                                                 → Spotify / медиаклавиши / звук
```

## Что нового

- **Окно настроек** (`settings.bat`, двойной щелчок по значку в трее): MQTT с проверкой
  подключения, автоопределение колонки и наушников, путь к Spotify, автозапуск.
- **Spotify только в трее**: окно прячется после запуска программой.
- **Прогрев спрятанного Spotify**: окно один раз показывается невидимым, чтобы Spotify начал
  играть (`spotify.warmup_seconds`).
- **«Сразу включать музыку»** после «включи Спотифай» (`spotify.play_on_launch`).
- Настройки применяются без ручного перезапуска: программа сама перезапускается при изменении
  `config.json`.

## Известные проблемы и планы

- Тумблер «Спотифай» в «Доме с Алисой» показывает неверное положение, если Spotify запускали или
  закрывали вручную (не через Алису). Пока: просто скажите нужную команду ещё раз.
- Shuffle (перемешивание) пока не поддерживается.
- Голосовой поиск треков — в версии `full/`, не доделан.

## 1. Нужен ли Spotify Premium

**Нет.** Lite-версия не обращается к серверам Spotify вообще:

| Функция | Как сделано | Premium |
|---|---|---|
| Вкл/выкл Spotify | запуск `Spotify.exe` и корректное закрытие процесса | не нужен |
| Следующий / предыдущий / пауза | системные медиаклавиши Windows (как кнопки на клавиатуре) | не нужен |
| Переключение звука | микшер Windows (SoundVolumeView) | не нужен |
| Поиск и включение конкретного трека | **в Lite нет** (см. Full-версию) | — |

Почему так:

- **Spotify Web API** (официальное управление через интернет: поиск, «включи трек на устройстве»)
  с 2024–2025 гг. работает для приложений разработчика, только если у владельца аккаунта есть
  Premium. Команды управления воспроизведением (`/me/player/...`) без Premium возвращают
  `PREMIUM_REQUIRED`. Поэтому в Lite он полностью убран.
- **Медиаклавиши** — это то же самое, что нажать кнопку ⏭ на клавиатуре. Spotify Desktop
  реагирует на них в любом тарифе, даже свёрнутый или спрятанный в трей.
- Ограничения бесплатного тарифа (реклама, лимиты пропусков, если Spotify их включит) — это
  правила самого Spotify; программа их не обходит и на них не влияет.
- Программе всё равно, какая сборка Spotify установлена: она ищет процесс `Spotify.exe` и
  файл по пути из настроек. Если ваш Spotify лежит не в стандартной папке — укажите путь в окне
  настроек (вкладка «Spotify» → «Обзор…»).

## 2. Состав проекта

| Файл | Назначение |
|---|---|
| `install.bat` | Создаёт `.venv` и ставит зависимости (один раз) |
| `settings.bat` | **Окно настроек**: MQTT, колонка/наушники, Spotify, автозапуск |
| `run.bat` | Запуск в фоне — значок в трее, без консоли |
| `run_console.bat` | Запуск с консолью и подробным логом (для проверки и поиска ошибок) |
| `list_audio_devices.bat` | Список устройств вывода звука в консоли |
| `add_to_startup.bat` / `remove_from_startup.bat` | Автозапуск без окна настроек |
| `main.py` | Сама программа |
| `settings_ui.py` | Окно настроек (tkinter, входит в Python) |
| `config.json` | Все настройки (окно настроек редактирует именно его) |
| `tools\SoundVolumeView\` | Бесплатная утилита NirSoft для переключения звука отдельной программы |
| `scripts\` | PowerShell-скрипты автозапуска и запасного аудиобэкенда |
| `tests\` | Автотесты (`pytest`), для разработки |

## 3. Установка

Требования: Windows 10/11 x64, Python 3.10–3.13 (**рекомендуется 3.12**), Spotify Desktop,
MQTT-брокер с навыком-мостом для Алисы (например, WQTT).

1. **Python.** Скачайте с https://www.python.org/downloads/ (Windows installer 64-bit).
   В первом окне установщика отметьте **Add python.exe to PATH**. Если Python уже стоит,
   проверьте в командной строке: `python --version`.
   > Очень свежие версии (3.14+) тоже обычно работают, но библиотека `comtypes` может писать
   > предупреждения. Если что-то не ставится — используйте 3.12.
2. **Распакуйте** папку `alice-spotify-pc-lite` куда-нибудь, где она будет жить постоянно,
   лучше без кириллицы и пробелов в пути, например `C:\Tools\alice-spotify-pc`.
   Не запускайте программу прямо из ZIP-архива.
3. Запустите **`install.bat`** (двойной щелчок). Он создаст папку `.venv` и скачает
   зависимости — нужен интернет, занимает 1–2 минуты. В конце будет `Done. Next steps`.
4. Запустите **`settings.bat`** и заполните настройки (раздел 4) → **Сохранить**.
5. Запустите **`run_console.bat`** и убедитесь, что в логе есть
   `MQTT state: connecting -> connected`. Закройте окно (Ctrl+C).
6. Запустите **`run.bat`** — в трее появится значок (может быть спрятан под стрелкой ˄;
   его можно перетащить на панель задач).
7. Настройте устройства в приложении «Дом с Алисой» (раздел 5) и проверьте голосом.

## 4. Окно настроек

Открывается: `settings.bat`, **двойной щелчок по значку в трее** или меню значка → «Настройки…».
После **«Сохранить»** запущенная в трее программа сама перезапустится с новыми настройками.

### Вкладка «Подключение»

| Поле | Что вписать |
|---|---|
| Сервер | адрес брокера из кабинета (у WQTT вида `mX.wqtt.ru`) |
| Порт | порт MQTT из кабинета брокера (у WQTT у каждого свой, например `16xxx`) |
| Логин / Пароль | логин и пароль **MQTT-брокера** из кабинета (это **не** пароль от входа на сайт) |
| TLS | для WQTT обычно **выключено**; включайте только если брокер дал TLS-порт (часто 8883) |

Кнопка **«Проверить подключение»** подключается к брокеру с введёнными данными и пишет результат:
`Подключено` или причину (`Not authorized` — неверный логин/пароль, `timed out` — неверный
порт/адрес или блокирует брандмауэр, ошибки SSL — не тот режим TLS).

### Вкладка «Звук»

- **Переключать только Spotify** (рекомендуется) — колонка/наушники меняются только у Spotify,
  остальной звук Windows остаётся где был.
- **Переключать звук всей Windows** — меняется устройство по умолчанию.
- **Колонка («включить»)** и **Наушники («выключить»)** — выпадающие списки найденных устройств.
  При первом открытии программа сама подбирает их по названию: «Станция», «Яндекс», «JBL»,
  «Динамики»… для колонки и «Наушники», «Headphones», «AirPods»… для наушников. Под каждым
  полем видно, подключено ли устройство сейчас (✔ / ✖).
- **Обновить список** — если колонку подключили после открытия окна.
- **Определить автоматически** — заново подобрать оба устройства.

Устройство должно быть **подключено и включено**, чтобы появиться в списке. Название можно
также вписать вручную или указать его уникальную часть (например, `Станция`).

### Вкладка «Spotify»

- **Spotify.exe** — путь к программе. По умолчанию `%APPDATA%\Spotify\Spotify.exe` (обычная
  установка с сайта). Под полем видно, найден ли файл. Для другой установки нажмите «Обзор…».
- **Только в трее** — когда программа запускает Spotify, его окно прячется, остаётся только значок
  Spotify в трее, а музыка играет (подробности в разделе 7).
- **Сразу включать музыку** — после «Алиса, включи Спотифай» программа сама нажмёт Play
  (продолжится последний трек). Без галочки Spotify просто запускается.
- **Нажатий «назад»** — `2`: «предыдущий трек» сразу переключает на прошлый трек (первое
  нажатие Spotify перематывает текущий трек в начало). `1`: как обычная кнопка.

### Вкладка «Общие»

- **Запускать вместе с Windows** — программа будет стартовать при входе в систему, сразу в трее.
- **Уведомления в трее** — всплывающие сообщения «Звук: …», «Spotify запущен» и т. п.
- **Подробность лога** — `INFO` обычно, `DEBUG` для поиска проблем.

## 5. Устройства в «Умном доме Яндекса»

Алиса сама не умеет слать MQTT. Нужен навык-мост «Умного дома» (WQTT, Intruder MQTT и т. п.):
в его кабинете вы создаёте виртуальные устройства и указываете, в какой топик что отправлять.

1. В кабинете навыка-моста создайте устройства по таблице.
2. В приложении **Дом с Алисой** → **+** → **Устройство умного дома** → найдите навык →
   **Привязать к Яндексу** → **Обновить список устройств**.
3. Распределите устройства по комнатам, проверьте названия (их Алиса и будет слушать).

| Устройство в Алисе | Тип | Топик команды | Вкл | Выкл |
|---|---|---|---|---|
| «Спотифай» | выключатель (on_off) | `alice/pc/spotify/power` | `ON` (или `1`) | `OFF` (или `0`) |
| «Колонка» | выключатель (on_off) | `alice/pc/audio/switch` | `SPEAKERS` (или `1`) | `HEADPHONES` (или `0`) |
| «Следующий трек» | выключатель / кнопка | `alice/pc/media/next` | любое | любое |
| «Предыдущий трек» | выключатель / кнопка | `alice/pc/media/prev` | любое | любое |
| «Пауза» | выключатель / кнопка | `alice/pc/media/play_pause` | любое | любое |

Пояснения:

- Значения `1/0`, `true/false`, `on/off` программа понимает сама (`payload_aliases` в `config.json`).
- Для «кнопок» (следующий, предыдущий, пауза) значение неважно: команда срабатывает на любое
  сообщение, поэтому «включи следующий трек» и «выключи следующий трек» делают одно и то же.
- Регистр в топиках важен: `alice/pc/...` — маленькими буквами.
- Топики состояния (`alice/pc/state/spotify`, `alice/pc/state/audio`) можно указать в навыке,
  чтобы в приложении «Дом с Алисой» отображалось реальное состояние.
- Удобные фразы вроде «Алиса, следующая песня» делаются **сценариями** в «Доме с Алисой»:
  «Если я скажу …» → «Умное устройство» → нужное устройство → «Включить».

Примеры голосовых команд: «Алиса, включи спотифай», «Алиса, включи колонку»
(звук Spotify → колонка), «Алиса, выключи колонку» (→ наушники), «Алиса, включи следующий трек».

## 6. Проверка без Алисы

Откройте командную строку в папке программы (в Проводнике в адресной строке наберите `cmd` и
нажмите Enter) и выполните по очереди:

```bat
.venv\Scripts\python main.py --list-devices
.venv\Scripts\python main.py --test spotify_power ON
.venv\Scripts\python main.py --test media_control NEXT
.venv\Scripts\python main.py --test media_control PREV
.venv\Scripts\python main.py --test media_control PLAY_PAUSE
.venv\Scripts\python main.py --test audio_switch SPEAKERS
.venv\Scripts\python main.py --test audio_switch HEADPHONES
.venv\Scripts\python main.py --test spotify_power OFF
```

`--test` выполняет команду прямо на ПК, без брокера. Если здесь всё работает, а голосом нет —
проблема в MQTT или в навыке-мосте.

Проверка через брокер (при запущенной программе в трее или в `run_console.bat`):

```bat
.venv\Scripts\python main.py --send alice/pc/media/control NEXT
```

Если трек переключился — брокер и программа в порядке, осталось проверить настройки устройств
в навыке-мосте.

## 7. Работа в трее, автозапуск, Spotify только в трее

**Значок программы:** зелёный — брокер подключён, жёлтый — подключение, красный — нет связи.

Меню значка (правый щелчок):

- **Настройки…** (также двойной щелчок по значку);
- **Показать Spotify** / **Спрятать Spotify в трей**;
- **Переподключить MQTT**;
- **Открыть лог**, **Открыть config.json**, **Открыть папку программы**;
- **Выход**.

**Автозапуск.** Галочка «Запускать вместе с Windows» в окне настроек создаёт ярлык
`Alice PC Controller.lnk` в папке автозагрузки (`Win+R` → `shell:startup`). Программа стартует
без консоли, сразу в трее. То же делают `add_to_startup.bat` / `remove_from_startup.bat`.
Если программу перенесли в другую папку — снимите и снова поставьте галочку.

**Spotify только в трее.** С галочкой «Только в трее» программа прячет окно Spotify после того,
как сама запустила его (команда «включи Спотифай»). Spotify при этом работает как обычно, его
значок в трее остаётся, медиаклавиши и переключение звука работают.

Spotify, ни разу не показанный на экране, не начинает воспроизведение. Поэтому программа
сама один раз показывает его окно **полностью прозрачным**, без фокуса и без кнопки на панели
задач, ждёт `warmup_seconds` (4 с) и прячет обратно — на экране ничего не появляется. Это
происходит после запуска Spotify программой, а также перед первой командой «пауза /
следующий / предыдущий», если Spotify запустился сам (например, своим автозапуском в трей).
Первая такая команда поэтому выполняется на несколько секунд дольше.

- Вернуть окно: щелчок по значку Spotify в трее или меню нашей программы → «Показать Spotify».
- Спрятать уже открытое окно: меню программы → «Спрятать Spotify в трей».
- Чтобы при **закрытии крестиком** Spotify сворачивался в трей, а не завершался, включите это
  в самом Spotify: Настройки → раздел про запуск и поведение окна → «Кнопка закрытия
  сворачивает приложение в трей» (название пункта зависит от версии Spotify).
- Если Spotify запускали вручную, он открывается окном как обычно — прячется только запуск,
  который сделала программа (или по пункту меню).

## 8. Переключение звука: как это устроено

В режиме «только Spotify» программа делает то же, что вы вручную в
**Параметры → Система → Звук → Микшер громкости → Spotify → Устройство вывода**. Выполняет это
NirSoft **SoundVolumeView** (`tools\SoundVolumeView\`, уже в архиве, оригинальные файлы).
Windows запоминает выбор для Spotify, поэтому он сохраняется и после перезапуска.

- Если Spotify в момент команды закрыт, выбор применится сразу после его запуска программой.
- Bluetooth-устройства с профилем `Hands-Free` (плохое моно-качество) автоматически
  пропускаются, если есть обычный Stereo-вариант того же устройства.
- В `config.json` можно указать несколько вариантов — используется первый подключённый:
  `"SPEAKERS": ["Яндекс Станция", "Динамики (Realtek(R) Audio)"]`.
- Вернуть Spotify на системное устройство: в микшере громкости выберите для Spotify «По умолчанию».

## 9. Частые ошибки и их исправление

Сначала смотрите лог: меню трея → «Открыть лог» (`logs\alice_pc.log`) или запустите
`run_console.bat` — там видно каждую пришедшую команду и ошибку.

### Установка и запуск

| Симптом | Причина и решение |
|---|---|
| `python` не является внутренней или внешней командой | Python не добавлен в PATH. Переустановите с галочкой **Add python.exe to PATH** (или установщик → Modify) |
| `install.bat` падает на установке пакетов | Нет интернета/прокси или слишком новая версия Python. Поставьте Python 3.12, удалите папку `.venv`, запустите `install.bat` снова |
| `run.bat` ничего не делает, значка нет | Запустите `run_console.bat` — ошибка будет видна в консоли. Значок может быть спрятан под стрелкой ˄ в трее |
| `The system cannot find the path specified` / нет `.venv` | Не запущен `install.bat` или папку переместили после установки. Запустите `install.bat` ещё раз |
| Окно с ошибкой `config.json` при запуске | Файл испорчен ручной правкой (лишняя или пропущенная запятая/кавычка). В тексте ошибки указана строка. Исправьте её или возьмите `config.json` из архива и заполните через `settings.bat` |
| «already running» | Программа уже запущена (значок в трее). Если значка нет — завершите `pythonw.exe` в диспетчере задач |
| SmartScreen/антивирус ругается на SoundVolumeView | Утилита бесплатная, но без цифровой подписи. Разрешите её или добавьте папку `tools` в исключения |
| Кракозябры в консоли | Косметика консоли Windows; лог и файлы в UTF-8 |

### MQTT

| Симптом | Причина и решение |
|---|---|
| Значок красный, `broker unreachable` / `timed out` | Неверный адрес или **порт**, брокер недоступен, блокирует брандмауэр/антивирус/VPN. Сверьте сервер и порт с кабинетом брокера, нажмите «Проверить подключение» |
| `Not authorized` / `Bad user name or password` | Неверный логин или пароль. Нужен пароль **MQTT-брокера**, а не пароль от аккаунта на сайте |
| SSL/TLS-ошибки, `wrong version number` | TLS включён на обычном порту (или наоборот). Для WQTT TLS обычно выключен |
| Подключено, но команды не приходят | В навыке-мосте другой топик (опечатка, заглавные буквы) или другой брокер. Проверьте `--send` (раздел 6) и таблицу в разделе 5 |
| Команды выполняются дважды или соединение постоянно рвётся | Запущены два экземпляра на разных ПК с одинаковым `mqtt.client_id`. Оставьте `client_id` пустым |
| После включения ПК выполнилась старая команда | `mqtt.ignore_retained` должен быть `true` (по умолчанию) |

### Spotify и медиаклавиши

| Симптом | Причина и решение |
|---|---|
| «Spotify не найден» | Укажите путь: настройки → «Spotify» → «Обзор…». Версия из Microsoft Store ставится в другое место — проще поставить Spotify с сайта spotify.com |
| Spotify запустился, но ничего не играет | Нормально: «включи Спотифай» только запускает программу. Начните воспроизведение командой «Пауза» (она же Play) |
| «Следующий трек» не работает | Spotify должен быть запущен и хотя бы раз начать воспроизведение. Проверьте `--test media_control NEXT`. Если не работает и обычная клавиша на клавиатуре — медиаклавиши перехватывает другая программа (другой плеер, утилита клавиатуры/мыши) |
| «Предыдущий трек» начинает трек сначала | Поставьте «Нажатий «назад»» = 2 |
| Медиаклавиши не действуют, когда открыта игра от администратора | Windows не даёт обычной программе управлять процессом с повышенными правами. Не запускайте игру от администратора или запускайте эту программу так же |
| Окно Spotify не прячется в режиме «Только в трее» | Spotify показал окно позже обычного. Нажмите в меню «Спрятать Spotify в трей»; если повторяется — пришлите лог |
| Spotify в трее не начинает играть, пока не откроешь окно | Программа делает это сама (раздел 7). Если на медленном ПК не хватает времени — увеличьте `spotify.warmup_seconds` в `config.json` до 6–8 |
| Spotify завершается вместо сворачивания | Включите в самом Spotify «закрытие сворачивает в трей» (раздел 7) |

### Звук

| Симптом | Причина и решение |
|---|---|
| `No playback device matches` | Устройство не подключено или называется иначе. Подключите его, настройки → «Звук» → «Обновить список» → выберите |
| Колонки нет в списке | Bluetooth-колонка выключена или подключена к телефону. Подключите её к ПК в «Параметры → Bluetooth». Яндекс Станция работает колонкой ПК только в режиме Bluetooth («Алиса, включи Bluetooth») |
| Переключилось, но звук со старого устройства | Spotify ещё не запущен — выбор применится после запуска. Иначе проверьте микшер громкости Windows для Spotify |
| Переключается весь звук Windows | Выбран режим «вся Windows». Выберите «только Spotify» |
| Ошибка про SoundVolumeView | Не удаляйте `tools\SoundVolumeView`. Если файл удалил антивирус — восстановите из архива и добавьте в исключения |
| Плохой моно-звук в наушниках | Выбран профиль `Hands-Free`. Выберите вариант без «Hands-Free» |

### Автозапуск

| Симптом | Причина и решение |
|---|---|
| Не стартует с Windows | Проверьте ярлык в `shell:startup`. Если папку программы переместили — снимите и снова поставьте галочку автозапуска |
| Стартует, но значок красный | Сеть ещё не подключилась — программа переподключится сама в течение минуты |

Подробный лог: настройки → «Общие» → «Подробность лога» = `DEBUG`.

## 10. Справочник

### Топики команд

| Топик | Значения |
|---|---|
| `alice/pc/spotify/power` | `ON` / `OFF` (`1`/`0`, `true`/`false`) |
| `alice/pc/media/control` | `NEXT`, `PREV`, `PLAY_PAUSE` |
| `alice/pc/audio/switch` | `SPEAKERS` / `HEADPHONES` (`1`/`0`) |
| `alice/pc/media/next` | любое — следующий трек |
| `alice/pc/media/prev` | любое — предыдущий трек |
| `alice/pc/media/play_pause` | любое — пауза / продолжить |

### Топики состояния (публикует программа)

| Топик | Значение |
|---|---|
| `alice/pc/status` | `online` / `offline` (retained; `offline` выставит брокер при обрыве) |
| `alice/pc/state/spotify` | `ON` / `OFF` |
| `alice/pc/state/audio` | `SPEAKERS` / `HEADPHONES` |
| `alice/pc/state/error` | текст последней ошибки |

### Командная строка

| Команда | Назначение |
|---|---|
| `main.py` | трей (обычный режим) |
| `main.py --settings` | окно настроек |
| `main.py --no-tray` | консоль без трея |
| `main.py --list-devices` | устройства вывода звука |
| `main.py --test КОМАНДА ЗНАЧЕНИЕ` | выполнить команду локально (`spotify_power`, `media_control`, `audio_switch`) |
| `main.py --send ТОПИК ЗНАЧЕНИЕ` | отправить сообщение в брокер |
| `main.py --config путь.json` | другой файл настроек |

### config.json

Обычно хватает окна настроек. Для тонкой настройки:

| Ключ | Описание |
|---|---|
| `mqtt.host`, `port`, `username`, `password`, `tls` | брокер |
| `mqtt.tls_insecure`, `ca_certs` | TLS с самоподписанным сертификатом |
| `mqtt.client_id` | пусто = `alice-pc-<имя ПК>` |
| `mqtt.qos`, `keepalive`, `reconnect_min_delay`, `reconnect_max_delay` | надёжность и переподключение |
| `mqtt.ignore_retained` | игнорировать старые retained-команды |
| `topics.*` | топики команд (можно сменить префикс `alice/pc`) |
| `button_topics[]` | «кнопки»: `topic`, `command`, `payload`, `trigger` (`any` / `on`) |
| `payload_aliases.<команда>` | перевод значений моста (`1/0`) в команды |
| `spotify.exe_path`, `launch_args`, `process_name` | запуск клиента |
| `spotify.close_timeout_seconds`, `pause_before_close` | закрытие (и пауза перед ним) |
| `spotify.tray_only` | прятать окно Spotify при запуске программой |
| `spotify.warmup_seconds` | сколько секунд Spotify, запущенный в трее, показывается невидимым окном, чтобы начал играть (по умолчанию 4) |
| `spotify.play_on_launch` | `true`: после «включи Спотифай» сразу нажать Play |
| `spotify.prev_presses` | сколько раз нажимать «назад» |
| `audio.mode` | `app` — только Spotify, `system` — вся Windows |
| `audio.devices` | `SPEAKERS` / `HEADPHONES` → список имён или частей имён устройств |
| `audio.backend` | `auto` / `pycaw` / `powershell` |
| `audio.roles` | роли Windows для режима `system` |
| `audio.app_routing` | путь к SoundVolumeView и список программ |
| `logging.level`, `file`, `max_bytes`, `backup_count` | лог с ротацией |
| `tray.notifications` | всплывающие уведомления |

Ключи, начинающиеся с `_`, — комментарии. Отсутствующие ключи берут значения по умолчанию.
Файл сохраняйте в UTF-8.

## 11. Обновление, удаление, безопасность

**Обновление:** выйдите из программы (трей → «Выход»), замените файлы `*.py`, `*.bat`, папки
`tools` и `scripts` новыми. Свой `config.json` оставьте. Если изменился `requirements.txt` —
запустите `install.bat`.

**Удаление:** снимите галочку автозапуска (или `remove_from_startup.bat`), выйдите из программы и
удалите папку. Вне своей папки программа оставляет только ярлык автозапуска и выбор устройства
для Spotify в микшере Windows.

**Безопасность:** `config.json` содержит пароль брокера — не публикуйте его и не отправляйте
в открытые чаты.

### Разработка и тесты

```bat
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python -m pytest -q
```
